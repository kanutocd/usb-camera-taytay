# USB Camera Taytay — Project Team

Provide a small, reproducible Linux Rust CLI reference application that captures or receives local USB-camera media and delivers durable, checksum-bound, resumable uploads to Lunsaran through Taytay, while keeping filesystem ingestion and pure Rust V4L2 capture as deliberately staged MVPs.

This area is for product development members and readers interested in the
project's architecture and delivery. USB Camera Taytay has two connected
goals: demonstrate Linux camera-media delivery through Taytay, and serve as a
reference application for the private Sandbox Loom project.
