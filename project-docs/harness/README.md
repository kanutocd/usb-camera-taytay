# usb-camera-taytay generated harness documentation

This directory contains proposed project documentation generated by
Sandbox Loom from the normalized project scope and the executable
harness artifacts under `.sandbox-loom/`.

- `AGENTS.md` — project-scoped coding-agent guidance.
- `ARCHITECTURE.md` — system structure, interfaces, constraints, and components.
- `IMPLEMENTATION.md` — concise implementation navigation and execution guidance.
- `REQUIREMENTS.md` — normalized stakeholder requirements and assumptions.
- `QUALITY_GATES.md` — the quality commands configured by the harness.
- [`../implementation/README.md`](../implementation/README.md) — phase and slice plan.
- [`../implementation/status.md`](../implementation/status.md) — current phase, slice, and runtime status.
- [`../backlog/README.md`](../backlog/README.md) — unapproved sketches and future work.
- [`../adrs/README.md`](../adrs/README.md) — architecture decision records.

These files are proposed review artifacts. The authoritative execution
configuration remains under `.sandbox-loom/`, and this documentation
cannot grant capabilities, credentials, approvals, or policy authority.

## Portable agent context

Any coding agent may consume this documentation without running Sandbox
Loom. Read `AGENTS.md`, `ARCHITECTURE.md`, `REQUIREMENTS.md`, the
applicable implementation slice, and approved ADRs first. Consult
`.sandbox-loom/implementation-plan.yml` and
`.sandbox-loom/implementation-status.yml` for executable scope and
progress. These files describe constraints; only Sandbox Loom may
authorize capabilities, approve side effects, run the workflow commit,
or finalize evidence.
