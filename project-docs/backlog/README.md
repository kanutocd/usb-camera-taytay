# usb-camera-taytay backlog

This directory contains unapproved project ideas and working material:
sketches, notes, design doodles, exploratory proposals, and possible
implementation slices that are not yet part of the approved delivery
plan.

Backlog content is informative only. It does not authorize coding-agent
work, change the policy profile, grant capabilities, or create a commit
boundary. Promote an item into `.sandbox-loom/implementation-plan.yml`
only after its scope, dependencies, acceptance criteria, quality gates,
and required approvals have been reviewed.

Keep approved implementation detail under
[`../implementation/README.md`](../implementation/README.md). Add
backlog notes here as separate Markdown files with a clear status and
owner when exploration begins.
